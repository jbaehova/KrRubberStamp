# Batch 2 C051부터 C100 최종 원고 기술 검증

최종 프로젝트 목표는 1,650개다. 이 보고서는 그중 C051부터 C100까지 50개의 최종 원고를 검증한다. 기술 검증은 모두 통과했다. 의미상 최종 승인은 root가 별도로 결정하며 사람 세무 전문가 검토는 대기 상태다.

원고 SHA256: `e24221c6905a1a82c129fe9845ada267eeea8681db0e932419d7c7ee39be63e5`

원고 쓰기 없이 현재 원고를 고정하고 새로 렌더했다. 기존 닫힌 부분 인계의 48개 전체 객체와 순서는 정확히 같다. 바뀐 두 객체는 root가 직접 작성한 C062와 C065다. 기존 독립 감사의 36개 유지 원고와 9개 전제 수정 및 3개 새 은행 원고를 그대로 보존했다. 기존 인계의 핵심 증거 14개는 인계에 기록된 SHA256과 일치했다.

## 독립 전체 답 검산

기존 48개는 닫힌 독립 검산의 기대값과 근거 SHA를 확인하고 현재 공용 계산의 전체 답과 다시 비교했다. 이전 기대값의 원고와 현재 해당 원고 전체 객체가 일치함을 먼저 확인했다. 두 새 원고는 root의 수기 전체 11개 필드 기대값을 비교했다. 엔진 출력으로 기대값을 만들지 않았다.

C062는 `8 × (12,500 - 500) - 2,000 = 94,000`과 `2 × 18,000 = 36,000`을 합친다. 상품 전체 할인 10,000원을 빼고 과세 배송 공급가 15,000원을 더해 공급가 135,000원과 매출세액 13,500원을 계산한다. 실제 전체 카드 148,500원의 발급 공제는 1,930원이다. 요청은 신고 계산 원단위 값이며 현금 납부액을 묻지 않는다.

C065는 받침 `4 × 32,000 = 128,000`과 가격 전액 할인된 덮개 `2 × (5,000 - 5,000) = 0`을 합친다. 상품 전체 할인 10,000원을 빼고 같은 공급자의 과세 배송 공급가 12,000원을 더해 매입 공급가 130,000원과 세액 13,000원을 계산한다. 전체 정상 전자를 수령하고 제작 전용 실제 인수를 확인해 매입세액 전액 13,000원을 공제한다. 무상 덮개의 표시 단가를 추가 대가로 합산하지 않는다.

## 실제 문서 및 반사실

- easy 15개, medium 22개, hard 13개다. 계획한 실제 원본문서는 254개이며 형식별 수는 PDF 109개와 XLSX 68개 및 HWPX 77개다.
- 새 실제 문서에서 복원한 50개가 검증을 통과했다. authored provenance와 gold schema 및 전체 trace를 확인했다. oracle exact 1.0과 null exact 0.0이며 요청 답의 총 필드는 199개다. 모델 API 호출은 0회다.
- 닫힌 반사실의 원문 edits를 현재 48개에 재생하고 이전의 before 및 after를 다시 대조했다. 폐기된 C062와 C065의 기존 반사실은 제외하고 새 root 반사실 두 개를 적용했다. 총 70개 중 61개는 요청 답 변경이고 9개는 정당한 제외 불변이다. 50개 모두 실제 요청 답을 바꾸는 반사실을 하나 이상 갖는다.
- C062 XLSX에서 상품 전체 할인을 10,000원에서 11,000원으로 바꿔 공급가와 세액 및 발급 공제가 함께 변하는 것을 확인했다. C065 PDF에서 받침 개당 단가를 32,000원에서 32,250원으로 바꿔 매입세액과 전액 공제 및 환급 계산이 13,100원으로 변했다. C051 HWPX에서 실제 확인된 반환액을 10,000원에서 8,000원으로 바꿔 실제 지급과 수령의 정산 잔액이 -2,000원으로 변했다.
- 세 원본 수정 모두 extraction_map과 task 및 gold와 trace의 바이트 해시를 고정했다. 답 변화는 실제 입력 원본의 복원으로 확인했다.
- C062와 C065 및 새 은행 C051과 C064 및 C081의 원본 PDF 총 9페이지를 실제 열어 확인했다. 관찰한 페이지에서 금액과 ID 및 날짜와 실행 상태가 읽혔고 잘린 문자는 발견하지 않았다. 모든 50개 문서의 시각 검토를 했다는 주장은 하지 않는다.
