# D101부터 D150까지 최종 통합 검수

현재 50개 원고를 승인한다. SHA-256은 `884fd3f88469b03e5bf171fbdda745118db9970e7c9dd6813afd3a59ee61f054`다. 독립 감사의 유지 46개 전체 객체와 순서를 보존하고 D123과 D137 및 D145와 D148만 직접 새 문제로 집필했다. 최종 난이도는 easy 15개와 medium 23개 및 hard 12개다. 전체 검수 승인 원고는 1500개이며 공개 실물 데이터는 기존 1200개다. 최종 프로젝트 범위는 Batch 1과 Batch 2의 2400개다.

root는 네 새 문제의 전체 사실과 실제 문서 필드 및 요청 답을 읽고 가까운 기존 구매 관계를 대조했다. 공급계정 이름이나 숫자 또는 포장 수만 바꾼 문제를 새 문항의 근거로 쓰지 않았다.

저자가 독립 Fraction 산식으로 계산한 전체 답 50개와 원자료 반사실 50개 및 새 결합 확인 8개를 검토했다. 현재 원고의 실제 문서 249개에서 50문항의 사실과 gold 및 schema와 trace 및 source provenance를 root가 다시 확인했다. PDF 101개와 XLSX 74개 및 HWPX 74개다. 새 실제 원자료 편집 6개는 PDF 2개와 XLSX 3개 및 HWPX 1개이며 extraction map과 gold 바이트를 유지했다. 날짜 PDF 편집의 중간 실패는 통과 수에 포함하지 않았고 최종 PDF 검증은 실제 숫자 셀을 사용했다. PDF 시각 검수 증거도 인계받고 대표 새 페이지를 root가 확인했다. 실제 3532개 필드에서 oracle은 1.0이며 null은 0.0이다.
