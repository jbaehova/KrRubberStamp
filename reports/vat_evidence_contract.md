# 부가세 활동 원자료 계약

`vat_activity_evidence_v1`은 개별 집필 사실을 기존 부가세 계산 엔진의 입력으로 옮기는 제한된 계약이다. 입력 자료에는 `purpose`나 `business_related`를 넣지 않는다. 영수증의 금액과 발행 사실을 읽고 실제 활동 기록에 연결한 뒤에만 두 필드를 계산한다. 계약은 [DATA_SPEC.md](../DATA_SPEC.md)의 개별 집필과 문서 복원 원칙을 따른다.

활동 해석은 자유 문장의 법률 판단을 자동화하지 않는다. `description`에는 실제 사용과 업무 경위를 읽을 수 있는 문장을 직접 쓴다. 결정적인 구조 사실은 참여자의 관계와 실제 장소 및 사용 대상 활동의 연결이다. `action: meal`만으로는 직원 식사와 거래처 식사를 구분할 수 없다. 참석자가 신고 사업장의 직원인지 외부 구매 담당자인지를 함께 읽어야 한다.

## 사실 구조

`facts` 최상위에 다음 세 항목을 둔다.

```json
{
  "source_contract": "vat_activity_evidence_v1",
  "operations": [
    {
      "operation_id": "가상-C002-제품판매",
      "description": "완성 목공품과 유상 체험상품 판매 및 주문 기념품 납품",
      "output_taxable": true
    }
  ],
  "activities": [
    {
      "activity_id": "가상-C002-활동-4",
      "transaction_id": "가상-C002-납품처식사",
      "document_ids": ["가상-C002-대표카드-0522"],
      "date": "2026-05-22",
      "action": "meal",
      "location": {"name": "가상나무식당", "kind": "restaurant"},
      "participants": [
        {"name": "가상김공방", "role": "proprietor", "organization": "가상한칸목공방"},
        {"name": "가상한구매", "role": "customer", "organization": "가상늘봄기획"}
      ],
      "operation_id": "가상-C002-제품판매",
      "description": "다음 분기 기념품 주문 협의 후 대표와 구매 담당자가 식사를 했다."
    }
  ]
}
```

해당 매입 증빙 행에는 `activity_id: 가상-C002-활동-4`를 기록한다. 영수증은 공급자와 결제액을 보여 주고 활동 기록은 참석자와 용도를 보여 준다. 매입행의 증빙번호가 활동 기록의 `document_ids`에 들어 있어야 하며 거래번호와 날짜도 일치해야 한다. 복수 증빙이 같은 거래를 기록했다면 활동의 증빙번호 집합은 연결된 모든 매입행의 증빙번호 집합과 정확히 같아야 한다.

| 필드 | 허용 사실 |
| --- | --- |
| `action` | `delivery`, `service`, `meal`, `vehicle_delivery`, `vehicle_lease`, `vehicle_service`, `ground_work` |
| `location.kind` | `worksite`, `restaurant`, `home`, `land_parcel`, `road` |
| `participants[].role` | `employee`, `proprietor`, `customer`, `household_member` |
| `operations[].output_taxable` | 해당 산출 활동에 대해 자료로 제공한 과세 여부인 불리언 |
| `operation_id` | 직접 사용 대상 활동의 ID. 가족 사용에서는 `null` |

직원과 대표의 조직명은 신고하는 `business_name`과 같아야 한다. 고객은 다른 조직의 참여자로 기록한다. `location`은 실제 장소의 `name`과 `kind`를 갖는다. 가족의 별도 사업장 인도에서는 장소를 운영하는 `organization`도 적는다. 참여자 이름과 조직명이 중복되거나 역할이 상충하면 거절한다.

원래 영수증의 `supplier_general` 및 `vat_separately_stated`는 증빙 사실로 유지한다. `vehicle_subject_excise`와 `vehicle_direct_business`도 자료로 제공하는 공식 차량 분류 사실이다. 활동 기록에서 공제 여부를 다시 쓰지 않는다. 자동차 인수나 임차 또는 정비가 아닌 활동에 차량 분류를 켜면 서로 다른 사실로 보아 거절한다.

## 제한된 해석 범위

| 실제 기록 관계 | 내부 엔진용 사실 |
| --- | --- |
| 직원 또는 대표가 작업장에서 수령한 재화나 완료된 용역이 과세 산출 활동에 직접 연결됨 | `business`, 관련 있음 |
| 식당 또는 작업장 식사에 해당 사업장의 직원이 참석하고 외부 고객이나 가족이 없음 | `business`, 관련 있음 |
| 식당 또는 작업장 식사에 외부 고객과 해당 사업장의 대표 또는 직원이 함께 참석함 | `hospitality`, 관련 있음 |
| 가정에서 가족이 사용하고 산출 활동 연결이 없음 | `private`, 관련 없음 |
| 가족이 운영하는 별도 사업장에 물품을 인도하고 신고 사업장의 산출 활동 연결이 없음 | `private`, 관련 없음 |
| 사업 활동에 연결된 자동차 인수와 임차 및 정비 | 각 차량 행위 클래스, 관련 있음 |
| 토지 필지에서 직접 수행한 지반 공사 | `land`, 관련 있음 |
| 물품이나 용역의 직접 사용 대상 산출 활동이 면세로 제공됨 | `exempt_business`, 관련 있음 |

가족의 별도 사업장 인도는 장소 운영 조직이 가족 참여자의 조직과 같고 신고 사업장의 대표 조직과 달라야 한다. 인도 행위만 지원한다. 자료가 없으면 일반 사업장이라는 이유로 사업 관련성을 추정하지 않는다.

고객과 직원이 함께 참석한 식사는 고객 참석 사실을 반영한다. 대표 혼자 먹은 식사는 직원 복지 사용을 확정할 수 없으므로 거절한다. 고객에게 주는 선물과 가족이 섞인 사업장 식사도 이 계약에서 해석하지 않는다. 차량과 토지의 사적 사용은 제공한 최소 구조만으로 분류하지 않는다. 과세와 면세에 공통으로 사용하는 매입 및 비율 안분 역시 지원하지 않는다.

`output_taxable`은 산출 거래의 자료상 분류를 출발 사실로 제공하는 제한이다. 자유 서술로 면세 여부를 새로 판단하지 않는다. 자동차의 법적 분류도 같은 제한을 갖는다. 세금 공제와 정산은 기존 엔진의 법규가 처리하며 활동 해석기가 새로운 공제 법규를 추가하지 않는다.

매출에는 활동 기록이 필요하지 않다. 매출만 있는 사례는 `activities: []`와 `operations: []`가 유효하다. 기존 엔진의 필수 필드를 충족하기 위해 매출에만 내부 `business` 및 `true`를 채우며 이 값은 매출 계산에 사용하지 않는다.

## 충돌 거절과 검증

활동 ID는 유일하며 한 거래 ID에 하나의 활동만 연결한다. 존재하지 않는 활동을 참조하거나 문서번호를 누락한 경우는 거절한다. 사용되지 않은 활동과 추가 증빙번호도 거절한다. 거래일과 활동일은 같은 ISO 날짜여야 한다. 실제 공급일과 주문일이 다르면 거래일은 실제 공급일로 기록하고 주문 경위는 별도 문장으로 남긴다.

`interpret(source)`는 입력을 변경하지 않고 엔진용 복사본을 돌려준다. `derivation_trace(source, normalized)`는 `VAT_ACTIVITY_EVIDENCE` 규칙 ID로 원자료와 증빙 연결 및 파생 결과를 기록한다. 이 규칙은 업무 데이터 계약이므로 `verified: false`이다. 정부 발표 규정이나 공식 계산 예시로 주장하지 않는다.

`tests/test_vat_evidence.py`는 실제 C002 자료를 렌더링하고 원래 사실을 복원한다. 원자료에 두 파생 필드가 없음을 검사한다. 고객 참석자만 같은 사업장의 직원으로 바꾸면 기존 영수증의 금액과 세무 사실은 유지되고 공제가능 매입세액은 60,000원 증가한다. 원래 C002의 납부액 1,038,400원은 유지된다. 이는 자유 문장 해석 정확도를 증명하는 시험이 아니라 명시된 사실 구조와 기존 엔진 연결을 검증하는 시험이다.
