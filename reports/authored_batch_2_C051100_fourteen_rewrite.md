# Batch 2 C051부터 C100 14개 수정 요청의 부분 인계

이 인계는 전체 50개 승인이 아니다. 요청한 14개 중 9개 전제를 수정하고 3개 전체 원고를 직접 새로 썼다. **C062와 C065는 미해결 재집필 대상으로 그대로 남겼다.** 새 원고 3개의 의미상 독창성과 현재 전제의 최종 수락은 root가 결정한다. 남은 2개를 기존 생존 증빙이나 금액 경계의 변형으로 채우지 않았다.

## 직접 새로 쓴 세 원고

- C051은 한 법인의 정상 확정 공급에서 실제 납부 110,000원과 이미 확인된 반환 10,000원을 양방향으로 보존한다. 순현금 100,000원과 신고세액 100,000원을 대조한다. 반환은 공급 취소가 아니며 새로운 환급 권리를 추론하지 않는다.
- C064는 하나의 실제 납부 실행이 두 번 전달된 정확한 복사본과 같은 금액의 별도 실행을 구별한다. 공급은 하나로 확정됐으며 현금 실행 ID로 200,000원을 계산한다. 공급 증빙 중복 제거의 문제를 단순히 재사용한 원고로 승인하지 않도록 근접 C060과 실제 답의 범위를 별도로 비교했다.
- C081은 실제 70,000원 납부와 미실행 50,000원 납부 계획 및 20,000원 반환 계획을 나눈다. 두 계획의 순액이 실제 잔액 30,000원과 같아도 실행된 현금이 아니다. 각 계획의 실행 반사실은 잔액을 반대 방향으로 움직이고 모두 실행하면 잔액이 0이다.

이 세 원고는 `new_two.yaml`과 `new_081.yaml`에 직접 전체 literal로 썼다. 기존 원고를 수치나 상호만 바꾸는 공장 또는 반복 생성 함수로 만들지 않았다. 은행 자료는 기존 공개 `vat_bank_reconciliation_v1`의 사적 장부 정책이다. 공동 송금 분배 계약을 사용하지 않았다.

## 법적 선행 신고 전제 7개 수정

C067, C070, C073, C088, C092, C098, C100의 앞선 신고를 같은 해 2026년 Q1 적법한 예정신고로 구체화했다. 직전 2025년 H2의 매출세액 20,000,000원에서 실제 매입세액 8,140,000원과 발행 공제 2,860,000원을 빼 실납부 9,000,000원을 복원한다. Q1에는 기존 발급 집계와 그에 대응하는 매출세액을 유지하고 실제 적격 매입 전자 원본을 추가했다. 공급가액과 별도세액 및 총액부터 실제 인수와 수령인 귀속까지 원본을 제시한다. 해당 실매입과 기발급 공제를 빼면 Q1 납부세액은 2,000,000원이다.

2,000,000원은 직전 반기 9,000,000원의 3분의 1인 3,000,000원에 미달한다. 이 납부세액 감소 기준으로 2026년 4월 24일 예정신고와 납부를 완료하고 종전 예정고지 결정은 없었던 것으로 명시했다. 공급가액 감소 조건은 주장하지 않는다. 기신고 매출과 매입 및 납부를 현재 추가 원장에 다시 넣지 않고 같은 해 발급 공제 사용액만 연간 잔여에 연결한다. 원형의 현재 공급 및 지급을 보존했고 전체 현재 계산 값도 같다.

[부가가치세법 제48조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0048&lsiSeq=276117&urlMode=lsScJoRltInfoR)와 [시행령 제90조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0090&lsiSeq=283641&urlMode=lsScJoRltInfoR)의 공식 원문을 직접 확인했다. 감소 요건 적용은 이 합성 원본에 대한 법령 적용 추론이다. 공식 숫자 예제나 사람 세무 전문가의 검토 완료라고 주장하지 않는다.

## 실제 난도와 자료 역할

C055는 실제 적격 고정대 카드 취소 후 일반 종이만 남은 증빙 부족이 현재 불공제를 만드는 공통 예외다. medium으로 바꿨다. 현장 인수 담당자의 실제 귀속 자료와 은행 승인 원본 및 발급 보관 원본과 발급기관 효력 통지의 네 실제 역할로 문서를 구성했다. 동일 표를 빈 패딩으로 쪼개지 않았다.

C072는 공식 비개별소비세 배송 차량의 유효 표시 정정 원본이 이미 확정된 정상 공제다. easy로 바꾸고 인수 및 작업 귀속과 공식 차종 및 확정 지급 원본의 세 자료로 모았다. 취소된 과거 미표시 원본을 현재 예외로 세지 않는다. 최종 전체는 easy15, medium22, hard13이다.

## 확인한 증빙과 한계

- 독립 감사에서 유지한 36개 전체 객체와 순서를 정확히 보존했다. 미해결 거절 C062 및 C065도 원형 그대로이며 승인하지 않았다.
- 50개 현재 전체 답을 독립 정수 및 Fraction으로 검산했다. 47개 증빙 선택은 기존 독립 감사의 직접 선택 계획을 대조했고 새 은행 3개는 신고 및 현금의 전체 중첩 답을 엔진과 별개로 계산했다. 엔진 정답을 기대값으로 복사하지 않았다.
- 선행 신고 7개는 실제 매입 전자 공급가액과 세액 및 총액의 관계를 각각 독립 검산했다. 각 Q1 실납부와 직전 반기 실납부 및 엄격한 3분의 1 기준을 기록했다.
- 현재 50개에 요청 답을 바꾸는 반사실이 하나 이상 있다. 총 70개 확인 중 61개는 변경이고 9개는 적법한 제외 불변이다. 수정한 12개 모두의 추가 반사실을 포함한다. 선행 신고의 다른 실제 매입 원본과 2,500,000원 납부도 여전히 3분의 1 미만이며 현재 정산에서 다시 차감되지 않는다.
- 현재 50개를 실제 PDF/XLSX/HWPX로 새로 렌더했다. 50개 provenance와 gold schema 및 trace를 확인했고 물리 검증 50개 통과다. 입력만 복원하는 oracle exact1.0, null exact0.0이다. 모델 API 호출은 없다.
- C051 PDF의 실제 공급가액과 C064 XLSX의 실제 두 번째 실행금액 및 C081 HWPX의 실제 계획 상태를 각각 원본문서에서 수정했다. extraction_map과 task 및 gold와 trace 해시는 고정한 채 복원 및 재계산에서 요청 답의 의도한 변화가 확인됐다.
- C051 전체 PDF 2페이지와 C088 선행 신고 전체 PDF 3페이지 및 C064 동일 실행 전달 PDF 1페이지를 직접 시각 검토했다. 관찰한 6페이지에서 핵심 금액과 날짜 및 ID 및 실매입 원본이 읽혔고 잘린 텍스트는 없었다.

현재 50개 기술 통과는 남은 거절 2개나 후보 3개의 편집 승인 대신이 아니다. human expert review는 대기 상태다. engine과 registry 및 acceptance ledger와 catalog 및 Git을 변경하지 않았다. 모든 쓰기 잠금을 root에게 반환한다.
