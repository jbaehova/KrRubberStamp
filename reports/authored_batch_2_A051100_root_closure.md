# A051부터 A100까지 최종 통합 검수

현재 원고 50개를 승인한다. 승인 SHA-256은 `c10a455de000694c1f534f4ea1df687f3c2a2620b32d502097d08c208bb31eae`다. easy 15개와 medium 22개 및 hard 13개다. 실제 문서 251개를 모두 다시 렌더링하고 사실 복원 및 gold와 schema 및 trace와 source provenance를 확인했다. 이 승인으로 전체 검수 승인 원고는 1450개가 됐고 공개 실물 데이터는 기존 1200개다. 프로젝트의 끝은 Batch 1과 Batch 2의 총 2400개다.

독립 감사가 유지한 43개 전체 객체를 보존했다. A061과 A087은 가족 문서 제목만 수정했고 사실은 그대로다. 재집필한 A054와 A057 및 A060과 A065와 A077은 가까운 이전 원고의 전체 사실을 읽고 마감 관계를 대조했다. 숫자나 이름 또는 자료 수와 요청 필드 변경만으로 새 문항을 인정하지 않았다.

| 문항 | 최종 검토한 실제 관계 |
| --- | --- |
| A054 | 두 사용자의 국세와 지방세 정정이 상쇄되어 합산 기납부액은 같아도 세목별 정산은 달라진다. 합산 납부액으로 각 세목의 납부를 대체할 수 없다. |
| A057 | 같은 회사와 기간의 다른 직원 고차수 원천을 먼저 제외한 뒤 본인 원천의 유효 차수를 선택한다. 다른 직원의 고차수는 본인 수정본을 지우지 못한다. |
| A060 | 같은 회사의 독립 두 지급기간을 합산하고 후반기 정정본의 동일 번호 재전송을 한 번만 쓴다. 별도 기간의 같은 지급액은 중복 사본이 아니다. |

| A077 | 같은 비과세 학자금이 지급총액과 비과세액을 함께 늘려 과세 급여는 유지하지만 교육비 공제 원액에서는 제외된다. 과세 급여 불변을 전체 정산 불변으로 처리하지 않는다. |

A077의 이전 저자 원고 `1501d067…`는 과세 회사 지원금을 교육비에서 차감한 전제가 잘못되어 승인하지 않았다. [소득세법 제59조의4](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=285523)의 교육비 제외는 비과세 교육비를 대상으로 한다. [국세청 비과세 학자금 안내](https://call.nts.go.kr/call/qna/selectQnaInfo.do?ctgId=CTG11920&mi=1318)는 업무 관련 교육과 회사 지급기준 및 일정 교육기간의 반환 조건을 설명하고 비과세 학자금의 교육비 공제를 배제한다. 최종 원고는 해당 세 요건을 모두 명시한 비과세 대학원 학자금으로 다시 정했다. 원천 담당자의 임의 확인으로 과세 지원금을 교육비에서 제외하는 전제를 유지하지 않았다. 이 후속 변경에서는 나머지 49개 전체 객체를 그대로 보존했다.

현재 새 다섯 문항의 전체 기대 답을 별도 정수 산식으로 확인했다. A077은 지급 5200만원에서 비과세 300만원을 뺀 과세 급여 4900만원이며 근로소득공제 1220만원 후 소득금액 3680만원이다. 본인 공제를 뺀 과세표준 3530만원과 산출세액 4035000원에서 근로 세액공제 66만원 및 교육비 공제 90만원을 차감한 국세는 2475000원이다. 같은 비과세 학자금을 300만원으로 바꾸면 지급 5300만원과 비과세 400만원이 되어 과세 급여는 여전히 4900만원이다. 교육비 공제는 75만원으로 줄고 국세는 2625000원이 된다. 지원을 제거하면 과세 급여는 그대로이며 교육비 공제는 120만원이고 국세는 2175000원이다.

최종 사실 기준 반사실 50개와 추가 관계 6개를 다시 확인했다. 요청 답 변화 47개와 제외 원자료 불변 3개가 통과했다. 실제 원자료 수정 4개도 통과했다. PDF에서 A054의 국세 납부와 A077의 실제 수업료를 바꿨고 XLSX에서 A057의 임차료를 바꿨으며 HWPX에서 A065의 학비를 바꿨다. 각 복원은 의도한 사실 하나만 바뀌었고 extraction map과 gold의 바이트는 그대로였다. A077의 새 PDF도 이미지로 확인했다.

승인 증거는 `reports/audit_evidence/batch_2/A051100_final/`에 있다. 이전 독립 감사의 동결 SHA와 반려 결정은 역사적 검수 근거로 남긴다. 이번 승인은 저장소의 명시된 계산 계약과 원자료 적격 전제에 대한 통합 검수다. 사람 전문가 검토는 별도 pending이며 전문가 승인을 주장하지 않는다. 모델 API 호출은 0회다.
