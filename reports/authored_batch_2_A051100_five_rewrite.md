# Batch 2 A051부터 A100까지 다섯 문항 재집필

독립 감사가 재집필을 요구한 A054와 A057 및 A060과 A065 및 A077을 각각 새 원고로 작성했다. A061의 두 문서 제목은 어머니에서 아버지로 수정했고 A087의 임차 문서 제목은 동생에서 자녀로 수정했다. 다른 43개 전체 객체는 순서까지 유지했다. 제목만 고친 두 문항을 포함한 나머지 45개 사실과 답 구조도 모두 유지했다. 이 보고서는 저자의 검증 인계이며 root의 최종 의미 승인과 전체 2400개 공개 통합 관문을 대신하지 않는다.

원본 SHA-256은 `9e81aa88c99a2ba2d9717d0ee7bf07441dfcd2974a4ae5266d4f406361e1722c`이며 새 동결 원고 SHA-256은 `1501d067a9090063c9e73f2ec01aa3f742ed870cb23e3c3ae6fee1a01bcf93af`이다. easy 15개와 medium 22개 및 hard 13개를 유지했다. 실제 문서는 251개이고 PDF 102개 및 XLSX 72개와 HWPX 77개다. easy 네 문항은 정상 확정 발급 자료를 대조하는 세 문서씩이며 해결되지 않은 충돌이나 미신고 복구를 예외 없이 숨기지 않았다. medium A077은 사후 회사 학비 지원 한 예외를 다섯 실제 자료에 연결했다.

실제 50개를 다시 렌더링하고 PDF 및 XLSX와 HWPX를 복원했다. 모든 원고 사실과 gold 및 schema와 trace 및 authorship provenance 검증이 통과했다. 계산 통과를 의미 중복 승인으로 보고하지 않았다.

실제 입력 파일도 새 문항에서 수정했다. PDF A054의 최신본 국세 250만원을 260만원으로 바꾸면 국세 정산은 -312500원이고 지방 정산은 88750원으로 유지된다. XLSX A057의 월세 840만원을 900만원으로 바꾸면 월세 공제는 153만원이다. A077의 과세 지원 여부는 해당 합성 원천 담당자가 확인한 입력 전제다. 이 사례로 회사 교육비의 모든 법적 과세 분류를 새로 인증하지 않는다. A065도 명시된 실제 재직기간을 사용하는 기존 계약만 따른다. 사람 전문가 검토는 계속 pending이고 모델 API 호출은 0회다. 최종 범위는 Batch 1과 Batch 2의 2400개이며 Batch 3 및 Batch 4는 없다.
