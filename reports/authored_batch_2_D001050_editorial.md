# Batch 2 D001~D050 독립 의미 및 문서 감사

감사 대상은 [cases_001_050.json](../authored/batch_2/D_extract/cases_001_050.json)의 고정된 50문항이다. 전체 원고 SHA256은 `4953af89dff42deafb1bf82dfadb12e8dd6fb9db1c7958e61989b36875e40ea5`다. Batch 1 D 원고 300개와 완료된 이 묶음 내부를 비교했고 다음 묶음은 제공된 7개 고정 snapshot만 읽었다. 작성 중인 D051~D100의 나머지 원고나 임시 파일은 읽거나 수정하지 않았다.

## 판정

**현재 50개 중 49개는 아래 범위의 의미 감사를 통과하고 D012 한 개는 재집필이 필요하다.** 기술 검증 일치를 개별 문항 다양성 승인으로 바꾸지 않았다. 다음 묶음의 고정 snapshot 7개도 현재 원고와 같은 완결 관계로 판단하므로 해당 소유자가 재집필해야 한다. 현재 원고와 다음 묶음 원고는 수정하지 않았다.

D012는 D004처럼 전량 인수 대금을 실행 선지급과 대조해 양수 잔액을 구한다. 두 송금과 한 송금의 차이 및 가격의 포함 표시와 요청 필드 축소가 유일한 관계 차이다. 새로운 중심 원자료 선택이나 귀속 판단 없이 금액 조건만 바뀌어 재집필을 요구한다. D009와 D001은 부분 포장 산술을 공유하므로 확대에서 반복 위험이 높다. 현재 D001은 납품 미이행 수량을, D009는 실행 지급이 없는 업체 청구를 중심으로 요청하므로 제한된 목적 차이를 인정했으며 같은 형태를 추가로 늘리는 근거로 삼지 않는다.

D011의 본체당 볼트 두 개라는 문장 자체는 어떤 요청 답의 계산 입력도 아니다. 그 문구를 한 개로 바꿔도 전부 불변이다. 현재 답은 주문 수량 대비 행별 미인수 현황을 보고할 뿐 조립 가능 개수를 자동 계산하지 않는다. 소개문에서 조립 수량 판단까지 검증했다고 확대하지 않는다. D048의 첫 문장은 실제 반품은 지지대에만 있으므로 “지지대 반품과 완충재 인수를 반영”으로 다듬는 편이 명확하다. 두 지적은 별도의 계산 오류나 현재 중복 탈락으로 집계하지 않았다.

## 독립 확인

- 엔진을 부르지 않는 별도 Fraction 산술로 50문항의 6개 전체 결과를 계산한 뒤 엔진과 공개 gold에 대조했다. 전부 일치했다.
- 저자가 제시한 62개 반사실을 독립 산술로 재현했다. 정상 답 변경 48건과 의도 불변 10건 및 입력 거절 4건이 모두 일치했다.
- hard 문항의 개별 예외를 분리하는 정상 반사실 13개를 추가했다. 다른 업체로의 귀속과 견적의 발주 전환 및 사건/지급 사본 제거를 포함한다.
- 실제 D001 및 D023과 D027 및 D037과 D045 및 D050의 PDF/XLSX/HWPX를 직접 복원해 고정 사실과 일치함을 확인했다. D027 주문 PDF 1쪽은 이미지로 다시 읽었고 0원 PIN 가격과 서로 다른 포장당 수량이 잘 보인다.
- 저자와 root의 전체 50문항/235문서 검증 증거도 읽었다. 독립 감사가 다시 실제 문서를 읽은 범위는 6문항이다. 나머지를 다시 육안 검사했다고 주장하지 않는다.

## 문서 수와 업무 범위

D023의 4문서는 서로 다른 두 업체 제안과 실제 예정 지급 검토 및 처리 약정이다. 모두 quote라 이번 정산이 빈 결과지만 quote 하나가 실제 order로 바뀌면 0인수 행과 업체 계정이 남는다. 따라서 빈 결과 자체나 예정 지급 0이라는 이유로 무의미 문서로 판정하지 않았다.

D027의 무상 핀은 실제 인수 4개와 미인수 2개를 요청 답에 남긴다. 무상→유상 반사실은 재고를 그대로 두고 행 대금을 0에서 732로 바꾼다. 0원 부속의 현물/금액 분리라는 예외가 답에 나타나며 장식으로만 들어간 항목은 아니다.

hard 12개는 모두 9문서다. 헤더와 가격표 분리만으로 새로운 문제라고 인정하지는 않았으나 각각의 주문 ID 및 행 가격과 독립 인수/반환 사건 및 실행 지급과 마감 약정에 고유 사실이 있었다. 빈 문서나 동일 내용의 무관한 복사로 9개를 채운 사례는 발견하지 못했다. 사본이 있는 D042와 D044 및 D046은 식별 중복 제거를 직접 판단하는 원자료다.

모든 VAT 명칭은 가상 사적 정산 약정의 산술이다. 공급가액의 신고 적격이나 법률상 환급을 판정하지 않는다. 날짜별 인수 우선/반품 후처리와 순량 음수 거절을 사적 계약 범위로 검사했다. 해당 범위를 실제 세무 법률 검증이라고 표현하지 않는다.

## 인계와 제한

이 보고서는 고정 SHA에 대해서만 유효하다. D012나 다른 원고가 수정되면 변경 문항을 새 SHA로 다시 읽고 기술 검증 및 의미 비교를 확인해야 한다. 미수정 49개까지 모든 4,800문항의 의미 다양성을 승인하는 보고서가 아니다. 독립 전문가나 실제 법률 자문을 받았다는 주장도 아니다. 모델 API 호출과 자동 원고 생성은 없었다.

원고 소유권은 root에 유지된다. 이 감사의 공개 변경 파일은 본 보고서와 `reports/audit_evidence/batch_2/D001050/` 아래 JSON 증거 3개다. 임시 계산 스크립트와 확인 PNG는 `tmp/audit_batch2_extract_001050/` 안에만 만들었다. 보고서 및 해당 증거 파일 잠금은 root에 반환한다.
