# Batch2 B051~B100 독립 편집 검토

검토한 원고 SHA-256: `283884fb2b96695e7074f30f28fd188ebf8d6d477908e45cc8f4ab390bb3122f`

결론은 유지43문항 및 재집필7문항이다. 원고 전체 승인은 아직 하지 않는다. 전문가 세무 검토도 완료됐다고 주장하지 않는다.

재집필 대상은 B061, B065, B068, B074, B076, B079, B082다. 두 easy와 다섯 medium을 교체해야 한다. 각 이유는 아래 문항별 표와 semantic_all50.json에 기록했다. 원고를 직접 수정하거나 accepted count에 더하지 않았다.

독립 Fraction 검산기로 원시 승인 선택을 다시 수행했다. 근태 시간은 분별 시각 순회로 실제 휴게 및 야간을 구하고 날짜별 휴일 시간을 합산했다. 공식 세액표는 원본 JSON의 표 데이터만 읽었고 engine/evidence/withholding/pension/health 계산 함수를 기대값 산출에 호출하지 않았다. 50문항 전체 답안을 각각 독립 계산하여 모든 필드가 일치했다. 저자 개입50건도 독립 재계산했으며 실제 요청47건 변화 및3건 적절한 불변량을 확인했다.

추가4건은 B076 경계가 작동하지 않는다는 재현, B089 승인상태의 실제 지급 영향, B091 밤계획 승인 조건의 실제 영향, B098 휴일별 포함 위치를 옮긴 분해 불변량이다. B089와 B091은 사용하지 않는 자료를 이유로 승인하지 않았다. 기존 가까운 관계에 추가된 상태 필터가 현재 답안의 실제 선택을 통제하는지 별도 반사실로 확인하여 유지했다. B098도 추가 어린이날 기본 대가48,000원이 현재 요청에 남는 것을 확인했다.

최종 rendered_closed만 사용해50문항의 실제 PDF/XLSX/HWPX를 복원했고 현재 원고 facts와 모두 일치했다. 독립 요청 답안은 실제 각 gold.json과 일치하며 provenance, gold, schema, trace 검사가50/50 통과했다.

새 물리 개입은 B066 PDF의 고정수당, B096 HWPX의 둘째 고객 계약시급, B094 XLSX의 첫 실행 사본 두 금액이다. 세 형식4개 실제 셀 또는 표 위치를 변경했다. 복원 facts 및 요청 답안이 모두 바뀌었고 extraction_map.json, gold.json, trace.json 및 task.yaml은 각 시험에서 원래 SHA 그대로였다. 세 PDF 첫 페이지도 직접 확인하여 행 및 제목 잘림이 없었다.
