# Korean document font

`NotoSansKR-Regular.ttf` is the weight 400 static instance of Google's Noto Sans KR variable font.

Source: https://github.com/google/fonts/tree/main/ofl/notosanskr

Downloaded on 2026-10-09 from the Google Fonts repository. The font is distributed under the SIL Open Font License 1.1 in `OFL.txt`. ReportLab embeds glyph subsets in generated PDFs. Workbook and HWPX font names request Noto Sans KR; viewers may substitute a locally available Korean font.
